V2.3 a été redécoupé en 6 phases livrables séparément.
Toutes les questions bloquantes ont été tranchées par l'humain.

DÉCISIONS PRODUIT FIGÉES (ne pas modifier sans nouvelle décision) :

PRICING
  - Free
  - €7.99 / mois
  - €59.99 / an  ← OFFRE MISE EN AVANT
  - €79.99 lifetime (paiement unique, option secondaire)
  L'annuel reste l'offre recommandée. Le lifetime est présenté comme
  "accès à vie au plan Marge Plus actuel". Les futures features à coût
  d'infrastructure élevé peuvent être exclues du lifetime, mais cela
  doit être explicite et cohérent dans la copy de la pricing page.

TRIAL
  - 7 jours d'accès complet à la première souscription.

CHAT FREE
  - 5 messages / jour.
  - Compte réel requis pour le chat persistant (pas d'anon persistant).

LIBRARY
  - Curation : ne garder que les contenus réellement prêts et substantiels.
  - Réduire le faux volume.
  - Si un contenu est vide ou trop faible : retirer ou archiver.
  - Préférer peu de contenus excellents à beaucoup de faibles.

STRIPE
  - Démarrer en TEST MODE.
  - Live seulement quand les flows sont validés.

STREAMING CHAT
  - PAS dans la première version.
  - Non-streaming d'abord, streaming plus tard si la base est stable.

INVESTIGATION LIBRARY PROD VIDE (résolu 2026-05-03)
  - Investigation effectuée : la library s'affiche correctement en prod.
    Les 13 contenus seedés sont bien visibles. Le rapport initial était
    transient (cache CDN, deploy en cours, ou race au premier load).
    Aucune correction de code nécessaire.

AUTRES DÉCISIONS (issues de l'audit, validées implicitement)
  - PAYWALL TRIGGERS (5) : post-bilan, post-diagnostic, contenu premium,
    7+ check-ins, ouverture chat.
  - ENTITLEMENTS : un seul helper centralisé (hasFeature / requireFeature).
    Frontend = cosmétique, backend = source de vérité.
  - SAFETY : couche obligatoire AVANT chat. risk_events sur tout déclenchement.
  - STRIPE webhook : idempotent via stripe_events table, écritures
    service_role only sur subscriptions / user_entitlements.

Phases proposées :

  V2.3.0  Curation library + architecture entitlements    3-5 j
